What This Project Is

BDS-07 is an academic capstone project built for the T.Y. B.Sc. Data Science program, Semester V. This website serves as a project showcase. It is not a commercial product or service.

Data We Collect

This website does not collect, store, or process any personal data from visitors. There are no analytics trackers, cookies, login systems, or data collection forms on this site.

Third-Party APIs

The underlying air quality prediction system uses data from the OpenWeather API and the World Air Quality Index (WAQI) API. These services have their own privacy policies. No user data is sent to these services through this website.

Hosting

This site is hosted as a static website. Standard server logs (IP address, browser type, access time) may be collected by the hosting provider as part of normal operations. We do not access or process these logs.

For questions about this project, visit the GitHub repository.
